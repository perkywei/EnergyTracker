# 更新日志

## 2026-06-28 — 能耗计算修复 + 功能增强

### 🔧 核心修复：油耗/电耗计算逻辑重写

**问题**：电耗/油耗用 `energy_added`（补能量）代替实际消耗量计算，导致数值严重偏差。

- 例：出发 100% 电 → 跑 56km → 剩 50% → 充电到 80%
  - 旧公式用充电量 `(80%-50%)×18.6=5.58kWh` 计算 → **9.96 kWh/100km**（错误）
  - 新公式用实际消耗 `(100%-50%)×18.6=9.3kWh` 计算 → **16.6 kWh/100km**（正确）

**修改**：`recalcAllConsumptions()` 改用前后两条记录的百分比差来计算消耗量：

```
消耗量 = (上次离开时% - 本次到站时%) × 容量 / 100
油耗   = 消耗油量 / HEV里程差 × 100
电耗   = 消耗电量 / EV里程差 × 100
```

同时去掉了跳过已有值的逻辑，所有记录统一全量重算。

### ✅ 数据校验机制

新增 `validateNewRecord()` 校验函数，在新增和编辑记录时触发：

**硬性拦截**（不可保存）：
- 总里程倒退（本次 < 上次）
- HEV 里程倒退（本次 < 上次）
- HEV 里程 > 总里程

**软性警告**（确认后可保存）：
- 总里程与上次相同（没开就加油/充电？）
- 加油量与百分比变化不匹配（油表仅显示整数%，允许 ±2% 舍入误差）
- 充电量 < 电池增量的 85%（充电桩读数应 ≥ 电池实际增量）
- 充电量 > 电池增量的 140%（损耗不可能这么大）

### 📄 分页功能

能耗明细分页，默认每页 10 条，可选 10/20/50/100 条。新增记录自动跳转到末页，导入后复位第 1 页。

### 👁️ 密码显示/隐藏

登录、注册、修改密码三个输入框右侧增加眼睛图标按钮，点击切换密码明文/密文。

## 2026-06-27 — Bug 修复

### 🐛 Bug #1：登录后用户数据"消失"

**原因**：服务器 `server.js` 新增了 `requireAuth` 中间件要求 API 携带 token，但前端未更新。

**修复**：在所有 fetch 请求中添加 `Authorization: Bearer <token>` 头，token 存在 `sessionStorage.ces_token`。

### 🐛 Bug #2：Chart.js 图表不显示

**原因**：新增的 helmet CSP 策略 `script-src 'self'` 阻止了 CDN 加载 Chart.js 和 SheetJS。

**修复**：CSP 白名单增加 `https://cdn.jsdelivr.net` 和 `https://cdn.sheetjs.com`。

### 🐛 Bug #3：提交表单导致页面刷新/退出

**原因**：
1. CSP 的 `script-src-attr 'none'` 阻止了内联 `onsubmit` 事件
2. QQ 内置浏览器 WebView 中 `<button type="submit">` 仍会触发原生表单提交

**修复**：
- 移除内联 `onsubmit="return false;"`
- JS 中添加 `e.preventDefault()` 事件监听
- 按钮改为 `type="button"`（最彻底的解决方案）
